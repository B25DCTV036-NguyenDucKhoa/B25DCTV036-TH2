 Chạy Phần A (TypeScript + DOM thuần)
    cd part-a-vanilla-ts
    npm install
    npm run dev

Chạy Phần B (React cơ bản)
    cd part-b-react
    npm install
    npm run dev

So sánh cách làm giao diện bằng DOM thuần (Phần A) và React (Phần B)


DOM thuần giúp hiểu sâu cơ chế hoạt động gốc của trình duyệt và không cần công cụ build phức tạp, nhưng code nhanh phình to khi nhiều trạng thái phụ thuộc lẫn nhau.
React giúp tách biệt rõ ràng giữa Dữ liệu (State/Props) và Hiển thị (JSX), giảm thiểu lỗi quên cập nhật giao diện khi quy mô ứng dụng lớn dần.
